SAME ANGLE / CODE REFERENCE

From a ghost photo to a saved pair

Same Angle helps a renter photograph the same spot at move-in and move-out, then print a dated before/after report. This map follows the automatic move-out capture through the finished source.

The main pieces

index.html opens the app. js/app.js chooses the screen and connects its buttons. js/camera.js opens the camera and makes JPEG photos. js/match.js compares the live view with the move-in photo. js/store.js keeps records and photo blobs in IndexedDB on this phone. js/report.js and css/print.css turn saved pairs into a printable report.

There are no external runtime services. Camera access needs HTTPS or localhost. Once the app is loaded, capture, matching, storage, and reporting work locally; a fresh offline launch is not cached.

One action: retake a spot

The automatic shutter fires once per attempt. The capture first lives in the in-memory drafts map; Keep pair commits it to the saved record. On a storage failure, the review stays open with a retry button and “Couldn't save on this phone”.

If the camera cannot open, cameraUnavailable() replaces the camera controls with a move-in preview (when present), an explanation, and Upload a photo. An uploaded move-out photo reaches pair review with a Manual label.

Reference route — three stops

This is a source-based reference route, not a claim of a completed interactive tour or a browser run during this final pass. Open each file and search for the named symbols.

  1. Enter the camera: js/app.js — render(), outScreen(), and its nested startMatch(). The hash route selects the spot; the screen layers <img class="ghost-photo"> over video. Opacity and Hide ghost change the guide, while the live image remains the scoring input.
  2. Decide when to capture: js/match.js — score() and watch(). Gradient correlation supplies the meter. THRESHOLD = 50, HOLD_MS = 500, and the fired flag control the one-shot callback. Back in outScreen(), the callback makes the frame green and calls shoot(true).
  3. Keep and display the evidence: js/app.js — finish(), pairScreen(), and persist(); then js/store.js — save() and database(). Keep pair saves the JPEG and spot metadata in IndexedDB. roomScreen() and js/report.js — renderReport() show the saved result.

To change this, start here

  • Match strictness or hold time: js/match.js, THRESHOLD and HOLD_MS. Rerun fixture measurements before choosing a value.
  • Ghost defaults and camera error wording: js/app.js, outScreen() and cameraUnavailable(). Appearance belongs in css/app.css, .ghost-photo and .camera-unavailable.
  • Empty-home guidance and sample button: js/app.js, homeScreen(); spacing is under .home-empty and .empty-steps in css/app.css.
  • Sample rooms and dates: js/store.js, loadSample(). The sample JPEGs live under img/sample/.
  • Report captions or page layout: js/report.js, renderReport() and photoFigure(); css/print.css controls printed pagination.

A practice to reuse

Measure a technical assumption with controlled examples before tuning it. The original threshold was 70. The checklist.md → Revisions records fake-camera measurements: same image 100, 3% shift 55, 5% shift 40, 10% shift 32, different scene 0. Threshold 70 demanded roughly better than 2% alignment, so it was changed to 50 to admit the 3% case while rejecting the 5% case.

tests/make-fixtures.sh turns sample photos into Y4M camera streams. tests/e2e.mjs, slice2(), measures them and asserts the automatic-capture boundary. The checklist records an all-slices pass from the earlier review; this final pass does not claim to rerun it. On another project, turn a vague assumption into a few repeatable inputs, measure the outputs, and retain checks on both sides of the chosen boundary.

These fixtures measure image similarity under controlled conditions. They do not establish handheld accuracy in changing room light or detect damage. Real-phone checks remain pending.

Run it again

From the app repository root:

python3 -m http.server 8080
# Open http://localhost:8080
# Map: http://localhost:8080/devpost/app-map.html

For the reviewing agent, with FFmpeg and Playwright/Chromium available:

bash tests/make-fixtures.sh
PW_ROOT=/path/to/playwright/project node tests/e2e.mjs all
PW_ROOT=/path/to/playwright/project node tests/shot.mjs

The tests create their own Node HTTP server on an automatic port. To inspect just the matching investigation, use node tests/e2e.mjs 2 with the same PW_ROOT. The screenshots cover 390×844 and 1280×800. This map itself opens as a local HTML file without a server or scripts.
